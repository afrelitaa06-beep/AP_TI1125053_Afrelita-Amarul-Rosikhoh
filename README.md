# AP_TI1125053_Afrelita-Amarul-Rosikhoh

Nama : Afrelita Amarul Rosikhoh

NIM : TI1125053

Kelas : TI 12 D

Program ini adalah aplikasi kasir sederhana yang dibuat menggunakan bahasa C++. Program berfungsi untuk:

Menampilkan daftar barang yang tersedia.
Meminta pengguna memasukkan jumlah barang yang dibeli.
Menghitung total harga belanja.
Menampilkan struk pembelian.

Program ini menggunakan prosedur tanpa parameter, yaitu fungsi yang tidak menerima nilai masukan (parameter) dan langsung menggunakan variabel global yang sudah tersedia.
Bagian ini berisi data barang yang dijual, yaitu:

Sarden dengan harga Rp15.000
Sabun dengan harga Rp5.000
Minyak dengan harga Rp20.000

Variabel jumlahBeli digunakan untuk menyimpan jumlah barang yang dibeli, sedangkan totalBelanja digunakan untuk menyimpan total pembayaran.
